# LOGICA DE PROGRAMACION
Sin ejecutar código en un computador, escriba manualmente un fragmento de código que permita intercambiar
los valores de dos variables numéricas.

- Valores iniciales:
* A=15
* B=30

- Valores esperados:
* A=30
* B=15
## SOLUCION:
Python:
Forma rapida en python
A, B = 30, 15
A, B = B, A

Forma larga
A = 30
B = 15
AUX = A
A = B
B = AUX

# B = 30
# A = 15
